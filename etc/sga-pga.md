# [Oracle] SGA vs PGA 구성요소 및 비교 정리

 **SGA**와 **PGA**는 오라클 데이터베이스 메모리 구조의 핵심구조이다.

---

## SGA vs PGA 비교

| 구분 | SGA (System Global Area) | PGA (Program Global Area) |
| :--- | :--- | :--- |
| **메모리** | 공유 메모리 (Shared) | 개별 메모리 (Private) |
| **특성** | 모든 프로세스가 공유하는 메모리 | 개별 프로세스 전용 메모리 |
| **할당 시점** | 인스턴스 시작(Startup) 시 | 프로세스/세션 생성 시 |
| **접근 주체** | 모든 백그라운드/서버 프로세스 | 특정 서버 프로세스 (단독) |
| **목적** | 데이터 캐싱 및 프로세스 간 정보 공유 | 정렬, 조인 등 개별 쿼리 작업 수행 |
| **주요 파라미터** | `SGA_TARGET`, `SGA_MAX_SIZE` | `PGA_AGGREGATE_TARGET` |

---

## SGA (System Global Area)

- SGA는 오라클 인스턴스가 시작될 때 할당되는 **공유 메모리 영역** 입니다. 
- 모든 사용자와 프로세스가 이 공간을 함께 사용합니다.

### 주요 구성요소
* **Database Buffer Cache**: 데이터 파일에서 읽어온 실제 데이터 블록을 보관하는 곳입니다.
* **Shared Pool**: 실행된 SQL 문장, 실행 계획(Execution Plan), 데이터 딕셔너리 정보를 저장합니다.
    * *Library Cache*: SQL 문장 및 실행 계획 저장
    * *Data Dictionary Cache*: 테이블, 컬럼, 권한 등 메타데이터 저장
* **Redo Log Buffer**: 데이터에 가해진 모든 변경 사항을 기록하여 장애 시 복구에 사용합니다.
* **Large Pool**: 대용량 I/O 작업, 백업 및 복구(RMAN), 공유 서버 프로세스 등을 위한 보조 공간입니다.
* **Java Pool**: 자바 코드를 실행할 때 필요한 메모리를 제공합니다.

### ① 데이터베이스 버퍼 캐시 (Database Buffer Cache)
* **역할**: 디스크에서 읽어온 데이터 블록을 메모리에 유지합니다.
* **효과**: 반복적인 데이터 요청 시 디스크 접근 없이 메모리에서 즉시 응답하여 성능을 높입니다.
* **Undo 관리**: 트랜잭션의 원본 데이터인 **Undo 블록**도 이 영역의 Undo 세그먼트에 보관됩니다.

### ② 공유 풀 (Shared Pool)
가장 중요한 캐시 영역으로, 특히 **라이브러리 캐시**가 핵심입니다.
* **라이브러리 캐시 (Library Cache)**:
    - SQL 문장, 파싱된 코드, **실행 계획(Execution Plan)**을 저장합니다.
    - **Soft Parsing**: 동일 SQL 유입 시 기존 실행 계획을 재사용하여 CPU 부하를 방지합니다.
* **데이터 딕셔너리 캐시 (Data Dictionary Cache)**:
    - 테이블, 컬럼, 권한 등 메타데이터 정보를 저장합니다. (Row Cache)

### ③ 리두 로그 버퍼 (Redo Log Buffer)
* **역할**: 데이터의 모든 변경 사항(DML, DDL)을 기록합니다.
* **장애 복구**: DB 장애 시 Redo Log를 사용하여 데이터를 복구합니다. (Undo의 변경사항도 여기에 기록됨)

### ④ 결과 캐시 (Result Cache)
* **역할**: SQL 쿼리나 함수 실행의 최종 '결과값'을 캐싱합니다.
* **효과**: 동일 쿼리 실행 시 연산 과정을 생략하고 결과만 즉시 반환합니다.

### ⑤ 기타 풀
* **Large Pool**: 대규모 I/O, 백업(RMAN), 병렬 쿼리 통신용.
* **Java Pool**: 자바 명령어 및 데이터 처리용.

---

## PGA (Program Global Area)
- PGA는 각 서버 프로세스가 생성될 때 개별적으로 할당되는 **비공유 메모리 영역** 입니다. 
- 다른 프로세스는 들여다볼 수 없는 전용 공간입니다.

### 주요 구성요소
* **Private SQL Area**: SQL 실행에 필요한 바인드 변수 값이나 실행 상태 정보를 저장합니다.
* **SQL Work Areas**: 데이터의 정렬(Sort), 해시 조인(Hash Join) 등 실제 연산 작업이 일어나는 공간입니다.
* **Session Memory**: 로그인 정보 및 사용자 세션과 관련된 상태 정보를 저장합니다.

---

## 요약
- **SGA (도서관)**: 공용 공간이며, 책(데이터)과 베스트셀러 읽는 법(실행 계획)이 보관되어 누구나 이용 가능합니다.
- **PGA (개인 책상)**: 나만의 연습장이며, 도서관에서 가져온 데이터를 정렬하거나 계산하는 개인 작업 공간입니다.
